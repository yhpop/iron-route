public distribution of this development snapshot on 2026-11-10. The earlier
technical provenance files are retained as historical records; their earlier
request for owner confirmation has now been answered.

owner's approval to publish original non-code artwork is not a separate CC0
dedication or an invented third-party license. Unless a file has an explicit
license below, original non-code artwork is included with the owner's
publication permission and remains copyright its owner. Ask the repository
owner for a broader asset reuse grant.
