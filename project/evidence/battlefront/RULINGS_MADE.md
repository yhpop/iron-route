# Controller decisions and costs

These decisions bound a private Mac/source candidate, not a public release or device acceptance. They are controller choices under the parent's explicit whole-battlefield priority; not claims of separate user approval for every implementation detail.

1. **Keep the initial slice at five actors, three existing ruin instances and no new texture family.** Renderer/platform scheduling cause remains unknown. Prefer coherent placement/material/ground use over higher-cost content. **Cost if wrong:** actual visual richness may still be insufficient; Mac can reject it without having added unmeasured load.
2. **Establish playable layout/real input evidence before presentation, retaining failures.** Preserve routes/terrain/collision/clock and real projectiles rather than tune firepower to force acceptance. **Cost if wrong:** staged development delays visible feedback; CPU proof does not replace the later device gate.
3. **Accept the qualified real retreat/hold-cover witness, not an instantaneous in-range disengagement claim.** The enemy fired before retreat, then returned within range and was blocked by actual wall for887ticks. Initial clear→blocked occurred outside range. **Cost if wrong:** a live in-range escape maneuver still needs independent device/play evidence; this package must not promise it.
4. **Adapt the prior performance task's main-hash test to the authorized new optional entry.** Retain old BASE identity, all exact main-only acceleration/negative/build/archive/Strv checks and build nonmutation; pin current candidate main. Reuse same-head actual CN/EN builds produced by the full suite. **Cost if wrong:** an overly broad adaptation could hide an entry regression, so independent task/whole review inspects the exact test diff.
5. **Restore exact historical external-test fixture dependencies, not fabricate new runs.**28 copied files are hash-bound to the frozen predecessor; original files remain untouched. **Cost if wrong:** stale evidence could be misrepresented as new proof; reports explicitly label it historical and source-bound, and the new mission has fresh full replays.
6. **Keep source/evidence directories after final review.** No operational Git is permitted; the user requires older versions and failed evidence preserved. The generic workflow's delete-after-merge step is therefore inapplicable. **Cost:** a larger private source artifact and retained work files, rather than lost provenance.

- Seconds-long scheduling remains unresolved; no safety/limit-step/focus change or performance-fix claim.
- Sparse reset-camera actor-dot schematics are not screenshots, full-mesh/DOM/touch or full-cycle occlusion proof.
- Two Sandfalcon routes and basic movement of all five chassis are not five complete routes or a reverse/near-truck collision fix.
- Initial mixed-head RED is rejected; corrected scalar RED has retrospectively captured base identity only. Later frozen-head focused/full-suite results do not rewrite that history.
- BF1 compressed evidence tooling (M1) and BF2 timeout descendant handling (M2) are explicitly presented to whole-candidate review, not silently discarded.
- Existing original-tank commercial rights remain unresolved; private source delivery is not blanket permission for public/commercial redistribution.
