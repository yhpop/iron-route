# 林脊伏击 · 补给线（未发布合并候选）

## 设计与复用
使用敌方车型 v3 的物理/火控/残骸为底；并入生态 v3 的草、Fox 骨骼动画、避让与许可菜单，以及共同的坡地、车队选路、待命和紧凑 HUD。不复制受限制的商业游戏资产，也不另造引擎。

单场玩法是把同一辆补给车送到北部，而非串联 demo 或强迫清空所有敌人。
- 东侧短硬路：装甲敌车移动封锁，装填时换位；可侦察等待、绕侧攻击或利用装填窗口护送。
- 西侧长低地：中央山脊挡弹，入口轻型木栅可碾压；需绕过北部固定炮位覆盖。
- H / 车队待命：只让补给车停车，可先开路再返回；仍可遭敌火。恢复后还需在护送距离内。
- 原坦克仍由玩家驾驶。敌车真实碰撞与残骸阻挡保留，不能遥控搬物或让大车沉水作桥。
- 草与狐狸是环境层，不提供弹道掩护、不阻挡道路、不作为击杀任务。

## 保留和边界
新增独立 mission-9030 / sortie=vertical-slice；原20关、进度键与玩家模型不变；旧 ridge-convoy / interceptor / living-convoy 入口保留。
任务参数是作者游戏平衡，不是经核实的历史坦克数据。
并未新增人物、其他武器或宣称世界观已完成。草目前仍有重复形状，合并版视觉/帧率、真实手机多指输入、长时间稳定性需要实机复验。未沿用两独立分支的 Mac 验收冒充本包通过。

## 验收顺序
1. 入口加载：只有一个车队、一辆敌车、两个狐狸；20关菜单仍20关。
2. 先试玩东西两路；至少各一场真实胜利，查车队不在路径转角/残骸/木栅误卡。
3. 待命/继续/脱离护送距离/敌人开火/坡后阻弹/绕侧命中。
4. 重开3次、暂停许可长文滚动、切原关；不残留实体、不破坏原进度。
5. 对照同设备旧分支记录帧时、P95和峰值，查同屏双方履带、草和骨骼的预算。
6. 手机短横屏摇杆、瞄准、刹车、双击缩放；CPU测试不能代替实机。
