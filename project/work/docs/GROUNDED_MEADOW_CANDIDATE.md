# 独立候选：坡面贴地与草簇变化

延续现有坦克游戏。基于玩法/静态上传候选（包SHA `c9589bce502d1a01fd5da926d4d9769bc61ce56f8fc5f62fad043ac267501ba9`），另存 `grounded_meadow_candidate/work`，不覆盖基线。

## 修改与取舍
原草把7片叶子做成固定一簇，只在簇中心取一次地形高度；坡面上叶根因此会悬空或埋进地形。现在每片叶子各有固定根位置和实际采样高度，使用位置种子分别变化根位置、长度、宽度、弯曲和方向。草簇中心、分布、随机序列、草层比例保持原样。

继续使用已锁定的 Three `InstancedMesh`、标准材质、Quaternion 和局部更新范围，没有引入新渲染引擎、第三方资源或自定义草着色器。

- 仍3600簇、1个InstancedMesh、151,200三角形；不增加草密度。
- 由3600个整簇实例改为25,200个叶片实例。矩阵存储从230,400增加至1,612,800字节（7倍），颜色与CPU初始化/局部更新工作也增加。不能把相同三角数与draw数量说成相同GPU性能。
- 根部收窄至2mm半宽、叶中仍较宽。只限制弯向上坡而会穿地的叶子；不再全局压直平地草。一次中间方案出现“针状草”回退，已通过同镜头对照识别并纠正。
- 碾压时根中心固定，叶片姿态平滑转向局部坡面法线；恢复仍约20秒。避免只缩短Y却让叶尖穿入上坡。
- 只有变化的草簇排入矩阵上传区段，合并重复/相邻范围，保留尚未被渲染消费的写入；静态不上传，初始化不遗留整块脏范围。

- 新问题均有失败→通过记录，包括根穿地、边界越界、初始化上传队列、过度直立和压平叶尖穿地。

`qa/grounded-meadow/measure.mjs` 是可重跑的CPU几何/上传请求审计。一个固定240次更新样本的请求数据量为约0.384MB，对照前版约51.38MB；这不是实际GPU流量或帧率测量。创建草视图的CPU时间本机样本约148ms，对照约18ms；独立复核约239ms，说明计时有波动，不作为性能保证。

## 视觉证据
`visual-evidence/comparison-close.png` 与 `comparison-medium.png` 为实际Three草几何、实例矩阵和颜色导出后，用Blender同镜头/灯光离线渲染的对照图。地形几何和相机完全一致，源码SHA已绑定；没有用AI图替代运行几何。

近景根部贴坡更自然，窄根消除宽三角底座；中景恢复不同朝向/弯曲/高度的轮廓。变化是有限改善，草仍明显是低多边形叶片，整体更纤细、地面露出略多，既非新增密草也非写实商业画质达标。

图片不含游戏地形贴图，灯光/色彩管理与游戏不同；不是浏览器、WebGL、动画、交互或性能证据。云端没有ego-browser，未用其他浏览器自动化替代，未操作Tabbit。
