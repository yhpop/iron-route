# 真实命中反馈 · 独立候选

## 玩家得到什么

代表关中，玩家的真实炮弹被正面装甲挡住时，原有目标方位行短时提示 **“炮位/装甲车正面挡弹 · 尝试绕侧”**；实际造成伤害时，提示 **“命中炮位/装甲车 · 伤害 45”**（数字取真实伤害事件，不固定写死）。

目的不是增加装饰，而是让玩家区分“打中了却没有伤害”和“绕侧有效”，特别是在静音时。原版已存在不同音效，不能说完全没有反馈；但两者粒子都属金属火花，HUD 没有清楚说明这个战术因果。

**不改**装甲、伤害、射速、视线、碰撞、AI、车队、地形、任务、存档或已有音效。原20关不启用本提示。这里只在 `design.integratedSlice === true` 的代表关显示；基于道路候选另存，不覆盖草地与道路包。

## 调研与许可决定

- 参考成熟坦克游戏将接触、未穿透和实际伤害区分的思路。Wargaming 的[官方装甲说明](https://wargaming.net/support/en/products/wot/article/10220/)明确说明命中装甲不必然减少车体生命。这里**不复制它的复杂弹道数值、UI、音效、图标或游戏资产**；该官方页标明版权所有，不能因为公开可读就当作开放素材。
- [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/ensure-no-essential-information-is-conveyed-by-sounds-alone/)支持把重要的声音信息同时用视觉传达。本实现用自写文字而不是仅靠颜色区分，也保留完整无障碍文本。没有复制其网页、图片或示例资产。
- 参考 Robert Nystrom 的[Event Queue 方法](https://raw.githubusercontent.com/munificent/game-programming-patterns/master/book/event-queue.markdown)：从战斗事件驱动独立提示，而不是把教程/UI 判断写进伤害系统。[仓库许可](https://github.com/munificent/game-programming-patterns/blob/master/LICENSE)区分代码 MIT 与文字/网站的 CC BY-NC-ND 4.0，不能把整本书当 MIT。本候选沿用工程已有事件队列，**未复制其示例代码、文本、图或样式**，未新增第三方依赖。

以上是方法研究与原创实现，不是取得商业游戏素材授权。所有原工程许可证继续保留；原玩家坦克的商业/再分发权利仍未独立核实，见 `assets/PROVENANCE.md`。

## 实现边界

- `src/combat-feedback.js`：只读、单条有界提示；消费玩家真实 `impact.value=shield` / `damaged.value`，不根据准星猜测命中，不把地形/友军/敌方炮弹算作成功。
- `src/main.js`：在每渲染帧排空之前读取所有固定步累积事件；选择/重试清空。模型不写回模拟状态，零新计时器、零保存字段。
- `src/campaign-ui.js` / `style.css`：复用既有方位行，不加悬浮面板。优先级是 **敌方即将开火预警 > 命中反馈 > 目标方向**；车队状态与血量保留。测量宽度后缩短文字，完整文本仍在 `aria-label`，相同布局缓存避免每帧反复长短替换。
- 阅读窗口为 **2.5 个模拟秒**；暂停时隐藏且模拟寿命冻结。它是尚待人眼验证的呈现时长，不是新增战斗平衡值。相同事件重复渲染不会续期。
- 消费者前提是本主循环的新鲜、按序批次：时钟每帧最多6步，立即消费并清空。独立审查指出，若外部调用者首次注入一个从未见过的很旧事件，当前模型仍会把它当新提示。现有接线没有该延迟队列路径；没有宣称这个模块可直接用于任意历史回放事件流。

- 新真实命中输入带、独立复放与提示观察在 `qa/combat-feedback/`；工具在候选的 `qa-tools/`，需要完整 `work` 源码布局，不能把增量包当完整源码。
- 旧20关历史严格验收仍保留前次38/41（40场全胜但旧源码绑定与impact元数据不匹配），未改写旧证据来制造全绿。

## 没有声称解决的事项

Mac 此前东线实际通关；近补给车 W+D 受真实接触限制，倒车拉开侧距可脱离。现有 `yieldForTankTurn` 与真实车身/炮管复合碰撞保留，本候选没有缩碰撞盒、自动挪车或宣称消除该问题。

旧版也出现鼠标静止时渲染帧推进异常，原因尚不明，本候选不将其归因于草/道路补丁，也未宣称修复。Mac 已在验前一组候选，**没有发起另一个实机任务**。没有本包浏览器截图、GPU/FPS测试或真实人眼可读性结论；测试DOM和离线输入证据不是实机画质验收。
