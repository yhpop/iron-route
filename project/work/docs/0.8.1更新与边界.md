# 0.8.1 复用说明

## 本版变化与限制

- 第 2 关调整开场接敌与东西两侧路线；车辆、武器数值不变。20 关数量不变。
- 敌方真实蓄力时，原目标提示行显示“瞄你/瞄车”、相对方向及剩余时间；拥挤时使用数量摘要。镜头与按钮位置不变，敌人仍可能画面外或被按钮遮挡，提示不代表已经解决可见性。
- 五个工业 GLB 的重复 PNG 字节只嵌入一次，加载时逐字节还原原 GLB；没有降低模型/贴图质量。并未实测加载速度、内存峰值或 FPS 提升。
- 写入进度前合并同键已完成存档，避免旧标签页抹掉更新的解锁/最佳成绩；保留最快成绩的完整记录，读取失败不盲写。它不是跨进程原子保存或页面即时同步。

## 无损打包契约

`node build.mjs` 通过 `scripts/prepare-art-payload.mjs`、`scripts/art-payload-plugin.mjs` 建立内存字节池，`src/art-kit-payload.js` 还原五个原始 GLB。没有生成资产作为前置条件，没有外部解码器或新依赖；坦克仍走普通二进制嵌入。原 GLB 可独立复用，网格、材质、节点、贴图与填充字节不变。

池大小为 5,206,679 字节，还原五份 GLB 共 11,354,124 字节。共享池是额外驻留内容，原加载器仍有自己的解析拷贝；较小的 HTML 不能证明内存减少或实机更快。PNG 邻接数据共享不是图像重新编码。现有二进制恢复、真实加载器资源所有权/清理、错误路径和构建入口测试随源码提供。

`prepare-art-payload.mjs` 可选输出的 .bin/JSON 是衍生诊断，不属于交付或构建必需文件。插件是每次构建的新快照，不承诺复用同一插件的增量 watch 行为。

## 证据边界

HUD 测试使用生产镜头和录制输入的 CPU 投影，并注入 DOMRect，不是浏览器像素。存档测试使用模拟存储，不能替代真实浏览器、多页面并发及设备恢复测试。当前 20 关、存档命名空间与原资产权利限制不变。
