# Newc42 articulated adapters

Author: Newc42. Source: https://newc-42.itch.io/german-low-poly-wwii-tanks
License: CC0 1.0 Universal https://creativecommons.org/publicdomain/zero/1.0/
Author page explicitly releases this named pack under CC0. Original FBX and Blender ZIPs have no standalone license file; saved author HTML and CC0 legal text are in candidate originals/newc42, hashes in evidence/armor. No Quaternius assets or permissions are used here.

Original models: Leichttraktor, Pz-III-J, Pz-VI-Tiger. Three geometry models, not skin variants. Pz-III is a same-type alternative to existing community PzIII, not an additional vehicle category. Source .blend uses a header unsupported by installed Blender 4.3.2, so source author's FBX was imported instead. No payment/login required.

Changes: uniform scale to hull widths 1.8/2.0/2.25 game metres, centre hull footprint, ground lowest track point, flip source heading for -Z/Y-up glTF, bake original world-space mesh transforms and insert explicit pivot nodes. Original mesh proportions and palette texture retained. Historical cross marking faces neutralised to the adjacent body-grey palette entry (10 Tiger, 17 PzIII, 12 Leichttraktor faces); no holes cut in hull/turret topology. Material roughness .82, metallic .12. These are game dimensions, not historical dimensions. No asset from another game was extracted.

`ARMOR_RIGS[id].rig` uses the existing controller's xyz-object interface. `file` is relative to assets/, gameScale is 1. `turretPivot` is hull-local; `barrelPivot` is turret-local; `muzzleLocal` is recoil-local. The source gun’s longest connected component is the shaft; its actual vertices define capsule start/end/radius. Other gun components (mantlet, short accessories) are enclosed in turretProxy over the full allowed pitch/recoil sweep, using analytic extrema. validatedMotion is elevation [-10,30] degrees and recoil [0,.15] metres; controller settings MUST remain within it. This uses existing box/capsule union and changes no collision interface. No vertices are removed to achieve narrower clearance. Track mesh is static; independent Wheel_* mesh nodes may rotate around local X. Track UV animation and suspension animation are NOT implemented. Rig data's capabilities describe structural availability, not gameplay implementation.

All nodes: TankRoot > TurretPivot > GunElevationPivot > RecoilPivot > Muzzle. Hull and Wheel_* are TankRoot children, TurretMesh is TurretPivot child, GunMesh is RecoilPivot child. Off-axis original weapons/pivots are retained; do not force muzzle x/y to zero.

Visual assessment: credible differentiated military silhouettes and running gear, but faceted low-poly models with a palette texture, NOT photorealistic/PBR war-damaged tanks. Close and gameplay-camera acceptance remains the integrator's decision. The offline images are actual Blender Cycles geometry renders; they are NOT game/WebGL frames or performance measurements.
