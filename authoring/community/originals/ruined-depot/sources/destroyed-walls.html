Preview: 

These are some destroyed walls I made for a game I have been working on,  they are fitting for the weekly challenge so i prepared them for public release.  They aren't intended to be finished assets as is,  but as a somewhat cleanish starting point to make more interesting structures.  Their main advantage is that they do have textures and UVs so it should save a lot of time for anyone who could use such models.

I provide a .ma file for maya users,  an .fbx for max users,  and .obj for all other modeling software.  

The models have 2 UV channels and 2 textures, intended to use as a layered material. 

Note that the .obj format only holds 1 UV channel per mesh,  so I included 2 .obj files one for each UV in case you can only read .obj,  all the data is there.

hopefully these save somebody some time. enjoy!

 

 

 

If you do publish something with them,  please post on my forums at www.lfagames.com to show it off!

 

if you like my assets,  come to lfagames.com for more tools and games ^_^
